# Neon Prime

Неоновая 3D-аркада для телефона на **Godot 4.7** (рендерер Mobile, портретная ориентация).

Игрок — светящийся куб внутри невидимого пространства 3×3×3. Через арену летят
лазеры, стены с проёмами и энерго-сферы. Нужно уворачиваться, перескакивая между
ячейками.

## Управление

| Действие | Телефон | ПК (для отладки) |
|---|---|---|
| Влево / вправо | свайп влево / вправо | `A` `D` / стрелки |
| Вверх / вниз | свайп вверх / вниз | `W` `S` / стрелки |
| Вглубь / ближе | кнопки **ВГЛУБЬ** / **БЛИЖЕ** | `Q` / `E` |
| Пауза | кнопка **II** | `Esc` / `P` |

Индикатор между кнопками показывает текущий слой по глубине (верхняя полоска — дальний слой).
Проекции куба на дне, задней и левой стенках арены помогают видеть, где он находится.

## Препятствия

Каждое препятствие может **стоять**, **вращаться** по кругу (в любую сторону) или
**качаться туда-обратно**. Сложность растёт со временем.

- **Лазеры** — сначала тонкие и мигают (предупреждение), потом становятся смертельными.
  У вращающихся лазеров всегда остаётся хотя бы один безопасный слой.
- **Стены** — сетка 3×3 с 1–3 проёмами (зелёная рамка), летит через арену.
  Чем дальше, тем меньше проёмов.
- **Энерго-сферы** — сначала видна траектория, потом летит шар.

## Бонусы

- **Заморозка** (голубой кристалл) — всё перестаёт вращаться и застывает в одном положении на время.
  Повторный подбор продлевает время.
- **Броня** (зелёное кольцо) — спасает от одной смерти. **Не стакается**: если броня уже есть,
  подбор даёт очки вместо второй брони.
- **Множитель очков** (золотая монета x2) — умножает очки. Подбор во время действия повышает
  множитель (x2 → x3 → … → x5) и обновляет таймер.

## Меню

- **ИГРАТЬ** — запуск игры.
- **НАСТРОЙКИ** — имя игрока, громкость звуков и музыки, чувствительность свайпа,
  вибрация, неоновое свечение (можно выключить на слабых телефонах), FPS, сброс прогресса.
- **ПРОКАЧКА** — за монеты (очки / 10) улучшаются эффекты: длительность заморозки,
  частота брони и неуязвимость после удара, длительность множителя, частота бонусов.
- **ЛИДЕРЫ** — топ-10 результатов на этом устройстве.
  Онлайн-рейтинг требует сервера (например, Firebase / Google Play Games) и пока не подключён.

## Очки

- 10 очков в секунду × множитель;
- +20 × множитель за каждое пройденное препятствие.

## Структура

```
scenes/main_menu.tscn      главное меню (стартовая сцена)
scenes/game.tscn           геймплей
scripts/game.gd            логика игры, управление, спавн, HUD, пауза, конец игры
scripts/main_menu.gd       меню, настройки, прокачка, лидерборд
scripts/game_data.gd       автозагрузка: сохранение, настройки, прокачка, рейтинг
scripts/sfx.gd             автозагрузка: синтезированные звуки и музыка (без аудиофайлов)
scripts/neon.gd            палитра, неоновые материалы, окружение со свечением
scripts/ui.gd              неоновые кнопки, панели, слайдеры
scripts/pickup.gd          бонусы
scripts/obstacles/         лазеры, стены, сферы и общий класс вращения
shaders/neon_grid.gdshader бегущая неоновая сетка пола
tests/                     автотест (бот) и генератор скриншотов
```

Всё строится из кода — модели и текстуры не нужны.

## Запуск и сборка

1. Открыть папку в Godot 4.7 и нажать **F5**.
2. Для Android: *Project → Install Android Build Template* / *Editor → Manage Export Templates*,
   затем *Project → Export → Android*.

Автотест без окна:

```
godot --headless --fixed-fps 60 --path . res://tests/smoke_test.tscn
```
