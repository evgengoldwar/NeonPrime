# Я — подземелье

Мобильный карточный рогалик на Godot 4.7 по дизайн-документу «Я — подземелье».
Игрок — хозяин подземелья: выкладывает ловушки и монстров в коридор, чтобы герои-грабители не добрались до Казны.

Открыть: Godot 4.7 → Import → `project.godot` → F5. Портретный экран 720×1280, управление мышью или касанием.

## Сборка APK для телефона

```
./build_apk.sh            # подписанный APK: build/ya-podzemelye.apk
./build_apk.sh debug      # отладочный APK: build/ya-podzemelye-debug.apk
./build_apk.sh install    # собрать и сразу установить на телефон по USB
```

Работает на Linux и macOS (на Windows — через WSL). Нужны только `bash`, `curl`, `unzip` и `tar`. При первом запуске скрипт сам скачает в `.build-cache/` Godot 4.7 с шаблонами экспорта, JDK 17 и Android SDK. Это около 3 ГБ и 10–20 минут, следующие сборки идут за минуту.

Ключ подписи создаётся в `keystore/` (папка не попадает в git). **Сохраните её**: Android обновит игру поверх старой версии только при подписи тем же ключом. Другая версия Godot задаётся так: `GODOT_VERSION=4.7.1-stable ./build_apk.sh`.

Чтобы поставить APK вручную, скопируйте файл на телефон и откройте его. Android попросит разрешить установку из этого источника.

## Проверка

`tools/smoke_test.tscn` проходит обучение и забеги за всех Хозяев через настоящие экраны и печатает ошибки:

```
godot --headless --path . res://tools/smoke_test.tscn
```

## Что есть

- **Бой** (раздел 3): 3 зала по 6 клеток, Тьма, рука, колода и сброс, тики строго по порядку из документа, все статусы (Замедление, Страх, Яд, Горение, Уязвимость, Оглушение, Проклятие), Броня, отряды, эффекты Вход/Выход/Аура/Засада/Смерть/Однократно/Постоянная/Сжечь.
- **Карты** (раздел 4): 59 карт: 14 базовых, 29 из крыльев, 4 особые и 12 карт локаций. У каждой есть версия «+». 14 реликвий.
- **Хозяева** (раздел 5): 6 Хозяев со своими пассивками и стартовыми колодами.
- **Враги** (разделы 6–8): 8 классов, 12 местных героев, 8 модификаторов элиты, 4 отряда, 6 боссов с двумя фазами и финальный босс Избранный.
- **Забег** (раздел 9): 6 локаций со своими правилами, карта этажа без пересечений путей, бой, элита, магазин, алтарь, 8 событий, сокровищница, награды, автосохранение.
- **Мета-прогресс** (раздел 10): Души, 5 крыльев Замка, 6 улучшений, Трофейный зал с коллекциями, 10 уровней Дурной славы, ежедневное подземелье, достижения.
- **16 экранов** (раздел 2), обучение при первом запуске, перетаскивание карт, долгое нажатие для подсказки, скорость x1/x2/x4, пропуск анимации, тряска экрана, вибрация, летящее золото и надпись «Комбо ×N».

## Устройство

Движок боя отделён от отрисовки, как требует раздел 11 документа:

| Путь | Что там |
|---|---|
| `data/*.json` | Все таблицы: карты (`cards.json`), герои и боссы (`heroes.json`), локации, реликвии, Хозяева, события, Замок (`world.json`). Новая карта — это новая запись, а не новый код. |
| `scripts/core/battle.gd` | Симуляция боя. `tick()` возвращает список событий («герой вошёл на клетку 3», «Шипы нанесли 12 урона»). Состояние целиком сохраняется в JSON. |
| `scripts/core/game.gd` | Забег, генерация карты этажа, встречи, награды, магазин, события, мета-прогресс и сохранения. Вся случайность идёт через один генератор с сидом. |
| `scripts/core/data.gd`, `sfx.gd` | Загрузка таблиц; синтезированные звуки и фоновый гул. |
| `scripts/screens/*.gd` | Экраны. Каждый строит свой интерфейс кодом. |
| `scripts/ui/` | Общие элементы интерфейса и окна забега (Колода, Реликвии, Пауза, выбор карт). |
| `assets/` | Пиксельные спрайты, плитки, рамки и шрифт. |

Сохранения лежат в `user://`: мета-прогресс в `meta.json`, текущий забег в `run.json`.

## Графика

Минималистичный пиксель-арт: иконки 12×12 для всех карт, героев, боссов и Хозяев, значки 8×8, плитки пола и стен для каждой локации и 9-patch рамки интерфейса. Всё рисует скрипт `tools/gen_sprites.py` из ASCII-шаблонов (палитра в начале файла). После правки шаблонов перегенерируй картинки:

```
python3 tools/gen_sprites.py
```

Шрифты (оба SIL OFL 1.1): Handjet для всего текста — высокие чёткие буквы, текст не меньше 24 px и с тёмной обводкой; Tiny5 для крупных заголовков, его размеры `UI.pfs()` округляет до кратных 8.

## Упрощения

- Музыки нет: звуки и фоновый гул синтезируются в коде.
- Таблица рекордов ежедневного подземелья хранится только на устройстве, сервера нет.
- Награды за достижения (рамки и скины) пока только перечислены, к внешнему виду не применяются.
- Есть только русский язык.
